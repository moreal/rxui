The other reading — a region that never mounts the rows outside the window — does break everything, and the eleven host sites that dereference `entry.node` unguarded are named (the only guarded one is inside `update()`, for an entry between creation and mount; `updateAt` fails a step earlier on `entry.handle`). **Nothing is emitted for it**: `runtimeAbi` stays 20. What *is* emitted closes ADR-0104 OQ1 — the hand-written backends make the same ownership claim and now say it, through one shared `FormDom.ownedState` reading identically to `StaticAttr.ownedState`, applied to every bespoke emitter rather than only the two the question named: Temperature (2), Validated Form (3), TodoMVC (3, two of them row-scoped) and Notes (1, the first `<textarea>` the rule reaches). The boundary is the property write and not the tag — Issue Browser's query field takes a literal value once and is never written again, so nothing can contradict it and no claim is made, which is Nest Lab's negative on the hand-written side. Four bundles change by pure addition with no existing line moved (TodoMVC +194, ValidatedForm +150, Temperature +109, Notes +50); **fifteen are byte-identical including Toggle Lab and the benchmark bundle, so the size baseline does not move** and every manifest and `graphHash` is unchanged. Witnesses are counts — four artifact gates pinning the sequences *and* the exact number of declarations, the Issue Browser negative, four browser tests walking the DOM count to zero through disposal — and one metric: TodoMVC's DOM-write assertion moves **203 → 209** for six row-branch mounts, the change made visible in the counter it belongs in.
